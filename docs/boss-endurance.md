# ボスのHPと即戦闘不能技

2026-11-11：ケファロックHP500、ユダチョウHP450。その他の能力・特性・技は据え置き。ユダチョウの夕立による3/8回復も最大HPに追従し、168回復になる。

チャレンジ開始時に相手の個体へボスフラグを付ける。ボスへの道連れ・滅びの唄は即戦闘不能の代わりに最大HPの1/3（切り捨て、最低1）のダメージ。残りHPが少なければ撃破できる。滅びの唄は従来のカウント終了時に一度だけ適用する。道連れは味方の犠牲を伴う。通常対戦およびボス戦の味方には従来の即戦闘不能が適用される。

ボスルールは特性ではないため、仮面・型破り・霊体で変更されない。守る・身代わりもこの割合ダメージを防がない。専用特性の封印、仕返しのダメージ計算、通常の技のやけど効果は維持する。HPは1/3ずつの切り捨てで減るため、HP500なら166、HP450なら150。与ダメージ扱いにはせず、仕返し用の被ダメ記録は増えない。

検証：tests/boss-endurance.mjsおよび既存テスト。
