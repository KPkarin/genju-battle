# お知らせと既読の保存

編成画面の「お知らせ」、戦闘中の「⋯」→「お知らせ」から、日付付きの更新履歴を確認できます。過去のお知らせは折りたたんで表示します。

起動時は、現在のブラウザでまだ表示していない最新の1件だけを自動表示します。ウィンドウを表示した時点で既読を記録するため、閉じずに再読み込みしても同じお知らせを繰り返しません。手動で開く場合はいつでも履歴を確認できます。アカウントによるログイン機能は追加していません。

既読IDはgenju_battle_news_seen_v1へ最大64件保存。編成の保存キーとは分離します。localStorageが利用できない場合はsessionStorageを補助に使い、両方使えなくてもページ内では繰り返しません。ブラウザのデータ消去や別ブラウザでは未読扱いになります。

更新内容はindex.htmlのUPDATE_NEWSに新しい順で登録します。公開済みのIDは固定し、次の公開時には新しいID・日本時間の公開日・タイトル・変更点を先頭へ追加します。過去の公開日はGitHubの実際のコミット日時を日本時間へ変換して記録しました。

全23種類のNodeテストが通過。update-news.mjsで初回最新1件、既読後の再訪、新バージョンでの一度だけの表示、履歴、フォーカスと背景の復帰、壊れた保存データ、保存拒否とセッション保存、空データ、戦闘乱数や編成への非干渉を確認。実ブラウザ確認は、実行環境が確認用サーバーのソケット作成を禁止したため完了していません。
