# 128pxの幻獣と戦闘演出（2026-11-22）

現在登場する25体の正面・背面を、確認済み128×128ドット絵と8コマの呼吸に更新。図鑑・編成・詳細・通常戦・ボス戦で共通の画像を使う。追加予定の6体は、能力値と習得技が未確定のため今回の登場対象には含めない。

## 素材

`assets/pixel-v1/manifest.json` に種族ID・アトラス順・寸法・再生間隔を保存。種族IDと保存キー、戦闘ルールのバージョンは維持する。

- 幻獣：正面・背面の2アトラス。横8コマ、縦25体。1コマ128px。合計2.32秒。部位別に調整済みの画像を使用し、旧32px用の変形は適用しない。
- 背景：通常・雨・夕立・砂嵐・雪の5枚、384×288。スマホ縦画面は4:3で全体を表示。横長画面は中央384×216を切り出し、縦横比を保つ。
- 天候：雨粒・湯気・砂・雪の透過画像。整数ピクセルで移動し、前のCSS雨模様は新描画時に非表示。天候が終わるとレイヤーを隠す。
- 状態：麻痺・やけど・凍結・眠り・眠気・混乱の見本と、流血5段階。1コマ160px、8列×2行、16コマで2.4秒。状態の併存に対応。混乱の戦闘ルールは新たに追加しない。

背景・幻獣・状態・技の各レイヤーを分離。スマホ縦画面は相手の幻獣と自分のHPパネルが重ならないよう高さを確保し、状態と技の描画位置は実際の幻獣の位置に合わせる。

`pixel-art.js` が画像を読み込む。読み込み前・失敗時は旧描画を使い、読み込み後に差し替える。天候と状態は必要になった画像を読み込む。画像の非同期読み込みで身代わり中の本体を再表示しない。

呼吸・天候・状態は装飾専用で、対戦用乱数やユニットの状態を書き換えない。画面非表示時は既存のアニメーション停止処理を使い、動きを減らす設定では静止コマを表示する。

## 確認

`node tests/pixel-art.mjs`：画像の寸法、400コマのアトラス参照、再生境界、読み込み前の代替、身代わりの非表示維持、向き、スマホの描画寸法、天候終了、状態11種。

既存の全43件のNodeテストに加え、Chromiumで390px幅と1360px幅、全50方向、天候4種、状態11種、状態の併存、身代わり、装飾による乱数の不変性、動きを減らす設定を確認する。通信対戦の実回線や実機Safariはこの確認には含めない。

ブラウザ確認は配信サーバーを起動して `python tests/pixel-art-browser.py --url http://127.0.0.1:8765/` で実行可能（PlaywrightとChromiumが必要）。通常のコマンド操作による1ターン、幻獣ウィンドウ、編成保存とお知らせの既読維持も確認する。
