# 透明感のあるUI（2026-11-13）

青緑と青紫の淡い光、半透明のパネル、低彩度の境界線へ変更。主要ボタンは明るい青緑、選択中は薄い発光、キーボードフォーカスは明確な輪郭で表示する。

編成、幻獣一覧、装備選択、戦闘コマンド、HP表示、ログ、各ウィンドウ、お知らせに適用。ボタンのサイズ・戦闘画面の配置・ゲームルール・保存形式は維持する。属性色とアイテム画像も維持する。

ぼかしは大型ウィンドウ・下部操作パネルに限定。非対応ブラウザは濃い半透明背景にフォールバックする。透明度低減設定では大型パネルの背景を不透明にし、モーション低減設定ではホバー移動を抑える。

UI・コンパクト戦闘・ボスUI2件・お知らせ・編成保存・基本処理の7テストを確認。Chromiumは実行環境のsetsockopt制限で起動できず、実際の画面レイアウトの目視確認は未実施。
