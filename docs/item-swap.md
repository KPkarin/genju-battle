# 奇術の交換条件

双方が持ち物を持ち、両方の持ち物が移動可能な場合だけ交換する。一方だけ・双方とも持ち物なしなら失敗。片方が固定状態でも双方とも交換せず、特性の封印状態や能力補正も変えない。失敗時は技を使用した扱いで気力を消費するが、交換演出は出さない。

固定状態は装備定義のunremovable、または個体のitemBoundで表す。既存の装備を勝手に固定品へ変更せず、今後の装備・効果に対応できる判定を追加した。技の実行時に現在の持ち物と固定状態を再確認し、コマンドの効果なし表示とAI判断でも同じ判定を使う。

身代わりは奇術を防がない従来の仕様を維持。無垢の仮面も双方が交換可能な持ち物を持っていれば交換できる。現在のチャレンジボスは持ち物なしなので、奇術による一方的な仮面の押し付けは失敗する。ボスの持ち物を新たに追加する変更は含めない。

検証：tests/item-swap.mjsと関連する既存テスト。
