# サランディ（第3チャレンジ）

大地・天空。HP480／物攻55／物防90／特攻110／特防90／速度105（合計930）。砂色の翼と風の尾を持つ浮遊幻獣の32px前後像。編成ボス限定で、通常の20体には追加しない。既存ボスと同じ道連れ・滅びの唄1/3ダメージのルールを使用する。

## サンドブレイクと爆発

大地・非接触特殊・爆発。威力50、命中100、気力35。追加効果は30%ひるみ。先手で未行動の相手にだけひるみが有効。はにうんどう有効時は60%。
技を実行した直後、命中判定前に砂嵐を残り5ターンへ設定する。外れ・守る・属性無効・風纏による反射でも砂嵐を発生させる。気力不足・ひるみ・麻痺・使用制限など、技自体を実行できなかったときは発生しない。
爆発区分は物理/特殊、接触、突進から独立したbooleanのexplosion。既存の種爆弾も爆発に分類。今回は分類のみで、既存技の威力や挙動は変更しない。

## 砂嵐と専用特性

発動ターン終了から5回、場にいる生存個体へ最大HPの1/16（切り捨て、最低1）ダメージ。複合属性でも岩石・大地のどちらかを含めば免除。相性倍率は掛けない。控えには作用せず、使用者が退場しても継続する。守る・身代わりでは防げず、霊体は間接ダメージを防ぐ。
岩石を含む個体は砂嵐中の特防が1.5倍。特性とは独立し、仮面や型破りで消えない。
専用特性「はにうんどう」は砂嵐中に防御・特防が1.5倍、技の追加効果の抽選確率が2倍（最大100%）。岩石の天気補正とも乗算される。仮面は特性の全効果を封印。型破りは防御側の特性による補正を無視する。攻撃側の追加効果2倍は防御側の型破りでは消えない。
天気は同時に一つ。夕立と砂嵐は互いを上書きし、砂嵐終了・夕立への変更で補正は直ちに消える。アベコベルームは砂嵐ダメージに影響しない。

## 風纏

天空の変化技、気力50、通常優先度。次に実際に受ける相手の特殊攻撃1回に対して、最終命中率（ランク・見切り適用後）から100ポイントを引く。0以下は乱数0でも外れる。命中が強化された相手は当てられる場合がある。必中技には命中低下が効かず、風纏は消費される。物理技・変化技、相手が行動不能・気力不足・技不発だった場合は消費しない。守るで防ぐ攻撃も消費しない。持続は次の対象特殊攻撃まで、交代で解除。特性ではないため仮面・型破りで解除しない。

外れた場合、受けるはずだった属性を固定し、威力を半分にした攻撃を元の攻撃者自身へ返す。特攻・特防・ランク・一致補正・相性は元の攻撃者が自分へ攻撃する計算。風纏側の特攻や特防は使わない。反射に追加の命中判定や消費気力はなく、追加効果・吸収技の回復・反動・再反射・天気の再発動も起こさない。元の攻撃者の身代わり・護りの札・スチームタンクなどの防御効果は適用する。スチームチョイスは元の命中判定で選んだ属性を維持する。

AIは特殊攻撃を見てから風纏の価値を高め、風纏を実際におどかすで阻止した相手には、使える攻撃がある間は再使用を控える。現在のコマンドは先読みしない。
