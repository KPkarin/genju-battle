# 技と気力溜めの調整

## 指定された変更

- 痺れ砂（しびれ罠）：交代で出た相手を50%で麻痺。天空・大地・雷電と状態異常の既存の防御は維持。やせ我慢では抽選成功時に発症予約。
- 岩投げ：威力60、気力20。
- 砂礫：威力45、気力25、命中時に物理防御を必ず1段階低下。身代わり・鏡膜の防御は有効。
- 体当たり：威力55、気力20。
- 守る：物理・特殊・固定ダメージの攻撃を完全に防ぎ、その攻撃の追加効果・吸収・反動・毒棘も発生しない。身代わりの耐久も減らない。変化技のまま、おどかすの対象から除外。消費気力は25から連続使用で50・100と倍増。状態異常技そのもの、やけど・寄生・設置などの間接ダメージは従来どおり。
- 気を溜める：選択したターンの攻撃被ダメージ1.2倍。行動前の攻撃にも適用し、ターン終了時に解除。固定反撃にも適用。やけど・寄生には適用しない。回復は25、集中なら50、ターン終了時回復は従来どおり。ボタンにリスクを表示。
