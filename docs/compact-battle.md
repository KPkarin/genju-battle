# スマホの戦闘画面と幻獣ウィンドウ

スマホの戦闘中はタイトルを省き、最上部から戦場を表示します。HPと気力を小さくし、バトルログはノベルゲームのテキストのように戦場下部へ重ねました。ログはその場でスクロールでき、「履歴」で全体を開けます。

四つの技を2列で表示し、その下に「気を溜める」「幻獣」を横並びに配置しています。双方の幻獣一覧と交代は「幻獣」ウィンドウへ移しました。特性や持ち物は通常の戦場と一覧に表示しません。横向きのスマホでは戦場とコマンドを左右に並べます。

## 幻獣の確認と交代

- 「幻獣」で味方3体と相手3体のHP・状態・場に出ている幻獣を確認できます。
- 味方の控えを選んで交代ボタンを押すと交代します。進行中・戦闘不能・場に出ている幻獣・拘束中などの条件を確定時にも確認します。
- 幻獣を約0.5秒長押しすると、特性・持ち物・実効能力値・能力変化・状態異常・足元の設置を確認できます。スクロールや指の移動では長押しを中止し、長押し後の指離しで交代先を選びません。
- 「詳細」ボタンと右クリックでも同じ状態画面を開けます。キーボードでは一覧カード上のIキーで詳細、Enter/Spaceで選択できます。
- 戦闘不能時や翻しによる交代先の選択も同じウィンドウです。閉じても選択待ちは保たれ、「幻獣」から再開できます。戦闘を退出すると待機を解除します。
- 戦場右上の「⋯」に音設定・相性とルール・ログ履歴・退出をまとめました。

反響中の気力溜め制限や、交代による状態のリセットなど、既存の戦闘ルールは維持しています。

## 検証

`node tests/compact-battle.mjs` で画面構成・双方の一覧・長押しのタイマーと中止・詳細の内容・交代の条件・選択待ちの継続と退出・反響中の操作を検証しています。既存機能を含む全13種類のNodeテストが通過しています。

実Chromiumで360×640、390×844、844×390、1360×1000を操作しました。スマホでは戦場が画面最上部から始まり、四技と下の二つのボタンまでページスクロールなしで収まり、横にはみ出さないことを確認しています。360pxと390pxではタッチイベントで長押しを実行し、全サイズで詳細・通常交代・交代先の選択待ち・気力溜め・メニューを確認しました。JavaScript例外はありません。実機のSafariと2端末の通信対戦は未検証です。
