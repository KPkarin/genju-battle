# やせ我慢・滅びの唄・編成保存

## 滅びの唄

使用ターンの終了時にカウント3を表示し、以降のターン終了時に2→1→0と進みます。0で戦闘不能になります。

| タイミング | カウント |
| --- | --- |
| 使用したターンの終了時 | 3 |
| 次のターンの終了時 | 2 |
| その次の終了時 | 1 |
| さらに次の終了時 | 0・戦闘不能 |

交代すると解除されます。すでにカウント中の個体へ再使用しても期限は延びません。カウント0の個体は護りの札や、そのターンの寄生回復で復活しません。

## 新特性「やせ我慢」

次の4体へ、従来2つの特性を残したまま3つ目の選択肢として追加しました。

| 幻獣 | 既存の選択肢 | 追加 |
| --- | --- | --- |
| 焔犬 | 不屈・好機 | やせ我慢 |
| 潮亀 | 重心・鏡膜 | やせ我慢 |
| 砕角 | 不屈・反骨 | やせ我慢 |
| 風燕 | 見切り・再生 | やせ我慢 |

麻痺・やけどを受けるとき、発症を予約して「やせ我慢している！」と表示します。その時点では実際の状態異常は付かず、速度低下・攻撃低下・行動失敗・やけどダメージも発生しません。

- ターンT：状態異常を受け、発症予約。T終了時はまだ発症しない。
- ターンT+1：通常どおり行動でき、終了時の通常ダメージ・回復処理が済んだ後に発症。
- ターンT+2以降：状態異常の通常の効果を受ける。

T+1終了までに通常交代・翻しで退くと発症予約が消え、再登場しても復活しません。風燕は翻しを覚えられます。発症済みの状態異常は従来どおり交代で治りません。静養は発症予約も治します。

予約は先着1種類だけです。状態異常への耐性や身代わりが防いだ場合、予約自体を作りません。無垢の仮面で特性が無効のときや、型破りの相手から受ける場合は即時に状態異常になります。すでに作られた予約は、その後の仮面着用で即時発症せず予定の期限で処理します。寄生・ひるみ・能力低下・滅びの唄は「やせ我慢」の対象外です。

## 編成保存

編集中の手持ち・技・特性・装備・並び順は自動保存し、保存結果を画面に表示します。空にした編成も次回まで空のまま残します。

「編成の保存枠」で編成1〜3を選び、「この枠に保存」を押すと、その時点の編成を別枠へ残せます。途中の編成も保存可能です。「この枠を読み込む」で復元すると、自動保存側もその編成になります。保存枠はその後の通常編集やクリアでは変更されず、保存ボタンを再度押すと更新します。空編成で保存済みの枠を上書きしません。

保存先は同じ端末・同じブラウザの当サイトのブラウザ保存領域です。GitHub Pagesと以前のSites版、別ブラウザ、別端末の保存内容は共有されません。ブラウザのデータ消去では消えます。保存が拒否された場合や容量不足の場合はエラーを表示し、成功と誤表示しません。保存済み編成の読み取りに失敗した場合も、ランダム編成で上書きしません。

互換キー：自動保存は既存の `genju_battle_draft_v1`、3枠の保存は `genju_battle_teams_v1`。旧編成はそのまま読み込み、重複種族・削除済みの技や装備・特性などは修復します。

## 確認

`node tests/stoic-perish.mjs` で発症・カウントの境界、免疫や型破り・仮面、交代・翻し・静養、死亡、双方視点の盤面と乱数一致を検証します。`node tests/draft-storage.mjs` で保存を共有した独立VMの再訪、3枠、空編成、データ破損・容量不足・読み取り拒否を検証します。これらは実ブラウザの保存ポリシーや実際のPeerJS通信を検証しません。
