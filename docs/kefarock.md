# ケファロック（チャレンジ）

編成画面の「チャレンジ」から3対1で挑戦。通常編成・通信対戦の選択肢には追加しない。
パキケファロサウルスの頭蓋、赤いモヒカン、鋲付きジャケットを描いた32pxの前後スプライト。
岩石・野生。HP230／物攻140／物防135／特攻50／特防85／速度50、合計690。

- ワイルドロック：岩石、物理接触・突進、威力130、命中90、気力50。実際に与えたダメージの半分（切り捨て、最低1）を反動として受ける。
- 野生回帰：野生の変化技、気力35。攻撃側の野生技の相性と、防御側の野生属性の相性成分を二乗する。等倍・無効は変わらない。次の攻撃を試みるまで継続し、その攻撃が野生なら威力1.5倍。外れ・無効・守るでも消費。麻痺・ひるみ・気力不足では維持。交代で解除。やけくそは攻撃なので消費。
- いしあたま：突進技の威力1.5倍。その技の反動のみ無効。毒棘・やけくそ・状態異常などを防がない。
- 突進：ワイルドロック、体当たり、翻し、翔撃。接触とは独立した分類。

複合防御は各属性の倍率を掛け算。一致補正はどちらでも1.5倍。アベコベルームは算出後の相性を反転する。
専用技はボス専用として通常の習得一覧に含めない。覚醒の攻撃用フラグは技開始時に更新し、連続技でも同じ攻撃全体に適用する。

検証：tests/kefarock.mjsと既存全テスト。実ブラウザの確認は環境のsetsockopt制限でChromiumが起動できず未完了。
