# 通常20体・技・特性の全体調整

公開日：2026-11-13。通信ルール `rebalance-v17`。通常20体の習得範囲、30技（新技1つを含む）、7特性、2装備、4体の能力を見直しました。ボス3体の専用技・専用特性・HPと、道連れ／滅びの唄の割合ダメージは維持します。

## 調整の基準

威力80・命中100・気力35、能力値100・等倍・一致なしを基準指数100とします。自然回復22、気力溜めは自然回復込み47。長期の攻撃頻度は `47 / (47 + max(実効消費 - 22, 0))`。実効消費には役立つ自己気力回復だけを織り込み、二重に加点しません。

指数は急所率1/16とダメージ乱数、端数切り捨てを含む期待値です。KO・速度・相性・行動阻止・天候・能力変化を全部ひとつに値付けするものではありません。勝率ランキングではなく、明らかな効率差を探すためのスクリーニングです。

## 中核の変更

- おどかす：行動阻止と先制を廃止。通常優先度で相手の行動種類に関係なく攻撃し、50%で物攻−1。守るで通常どおり防げます。
- 気合い・精神統一・結界：単独能力＋2、気力35。根を張るは物防＋2・速度−1、気力30。回避の舞い上がるは＋1を維持し気力35。
- 仕返し：気力35、受けた攻撃ダメージの1.5倍、上限は使用者最大HPの1/2。身代わりと無効相性を適用し、半減・抜群では固定値を増減しません。気力溜めの被ダメ増加を含めても上限を超えません。
- 幻痛：気力35、最大10を奪って回復。闇喰らい：気力40、吸収30%。貪食込み45%。
- 反響中も通常交代が可能。交代で反響が解けます。反動ターンの入力スキップと、技を使えないときのやけくそは維持。
- 全員共通技は体当たり・守る・気合い・精神統一・結界の5つへ。先制・反撃・回復・妨害を個体別に配分。

## 保存済み編成

自動保存と3つの保存枠のキーは維持。変更前の元データはブラウザ内の別キー `genju_battle_before_balance_v17` に一度だけバックアップし、以降は上書きしません。バックアップ不能の場合は自動保存を止め、元の自動保存データを保護します。保存枠そのものは読み込みで上書きしません。

完全な旧編成で習得できなくなった技は、新しい習得範囲から決定的に4枠へ補完。合法な技・幻獣の順番・持ち物は維持し、ワカクサルの旧好機は反骨へ変換。部分編成は合法な技だけ復元します。ボスを通常編成へ持ち込むことはできません。通信は新ルールの合法な編成だけを受け付けるため、双方で再読み込みが必要です。

## 検証

既存テストを新仕様へ更新し、専用の挙動・編成移行テストを追加。新旧ルールの係数、保存データの原本保護、身代わりと固定ダメージ、確率境界、編成生成、対人戦の同期を検証します。種を固定したAI同士の100試合で有限HP・気力の範囲と試合終了も確認します。これは人間同士の勝率検証ではありません。実ブラウザはChromium起動時のsetsockopt制限（Operation not permitted）で確認未完了。ライブPeerJSも未検証です。
