# 戦闘バランス調整

## 空属性と舞い上がる

無属性から空属性への攻撃は、無効から等倍（1倍）に変更しました。地属性から空属性への無効は従来のままです。舞い上がるは回避+1だけを上げ、素早さは変化しません。

## 身代わり

耐久は従来どおり最大HPの1/4で、通常の攻撃ダメージを肩代わりします。防げる追加の効果は、状態異常・能力低下・新たな寄生種です。

- 反響・封技・挑発・渦潮の拘束は通ります。渦潮の素早さ低下は防げます。
- ひるみ、おどかすによる行動中断、幻痛の気力吸収も通ります。
- すでに受けていた状態異常や寄生は、身代わりを作っても解除されません。
- 身代わりを壊した一撃の余剰ダメージは本体へ流れず、その一撃に付随する状態異常・能力低下も防ぎます。連続技の次の一撃から本体へ当たります。

## 粉砕岩

岩属性・物理、1回の威力20、命中100、消費気力30。攻撃回数を1回だけ抽選します。

| 回数 | 確率 |
| --- | ---: |
| 2回 | 35% |
| 3回 | 35% |
| 4回 | 15% |
| 5回 | 15% |

命中判定と気力消費は技全体で1回、ダメージ・急所は一発ずつ計算します。身代わりが壊れた後のヒットは本体へ当たります。護りの札で途中の一撃をHP1で耐えても、後続のヒットで倒れます。相手または使用者が倒れたら残りの攻撃は止まり、控えの個体へは続きません。毒棘は本体に当たった各ヒットで発動し、身代わりだけに当たったヒットでは発動しません。

## アベコベルーム

幻属性・変化技、消費気力30。使用した瞬間から、使用ターンを含む3ターン、双方の攻撃技の相性を反転します。

| 通常の相性 | ルーム中 |
| --- | --- |
| 2倍 | 0.5倍 |
| 0.5倍 | 2倍 |
| 無効（0倍） | 4倍 |
| 等倍（1倍） | 1倍 |

反転は攻撃側の技属性と防御側の属性の通常相性に適用し、その後に破魔石などの補正を加えます。場全体の効果なので交代や白霧で消えません。再使用で残り3ターンに戻り、ターン終了時に1回だけ減少します。戦闘画面に残りターンを表示し、終了すると通常相性へ戻ります。

岩棘・痺れ砂の設置効果と、炎がやけどにならない等の状態異常耐性は反転しません。編成画面の相性表は通常相性を表示し、戦闘コマンド・AI・交代候補は現在の反転状態を参照します。

## 確認方法

`node tests/balance-update.mjs` で指定確率の境界と比率、連続技・身代わり・護りの札・途中KO、反転相性の全100組、3ターンの期限・交代・UI・AI、ホスト/ゲストの盤面と乱数の一致、最終KOで勝利処理が1回だけ走ることを検証します。モーション、音源、編成保存などの既存8テストも別途実行します。実ブラウザと実通信での確認は含みません。
