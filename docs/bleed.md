# ダマスデビル・流血

暗闇・野生の通常幻獣、ダマスデビル（22体目）。HP105・物攻120・物防75・特攻45・特防75・素早さ130、合計550。特性は貪食／やせ我慢。正面・後ろ姿・呼吸アニメーション対応。

かみちぎる：野生の物理接触技、威力40・命中100・気力25。本体に実ダメージを与えると流血を1段階重ねる。守る・身代わり・外れ・相手不在では流血を与えない。確率付き追加効果ではない。

流血は通常の状態異常とは別枠。5段階まで重なり、ターン終了時に最大HPの1/2/4/8/16%（小数切り捨て、最小1）のダメージ。霊体の既存の防御対象には含めない。交代・翻しで解除しない。

HP回復は共通処理を通り、実際にHPが増えた1回につき流血を1段階下げる。満タンで回復0の場合は下がらない。貪食・吸収・光合成・静養・エラ呼吸・命の実・再生・寄生種・スチームタンク・夕立の回復に対応する。能力上昇・気力回復・護りの札は対象外。

やせ我慢は流血も受けた次ターン終了時まで遅延する。発症予約は通常の状態異常予約と独立し、合計5段階まで。予約分も回復で軽減できる。既に発症した段階を先に減らし、その後に予約を減らす。流血の予約も交代では解除しない。発症した終了時には流血ダメージを与えず、次のターン終了から与える。通常状態異常だけを治す鈴や早熟は流血を解除しない。

終了処理では命の実→既存の状態異常・寄生→流血→天候→発症予約の順に処理する。命の実・やけど・寄生の減少と吸収回復・流血・天候の各HP変化を、理由のテキストとともに約0.8秒以上の間隔で表示する（既存のログ待ち時間も加味）。命の実で段階が下がれば、その終了時の流血ダメージも軽減される。控えの流血ダメージは発生しない。
