# UIと操作の更新

## 月下の闘技場

既存の幻獣のドット絵と月夜のフィールドを使い、夜紺・青緑・金・朱色で統一しました。PCでは手持ち3体と戦闘画面を横に広く配置し、狭い画面では指で押しやすいサイズへ切り替えます。

初めに手持ちを表示し、その下に18体の図鑑を配置しています。各幻獣をタップして能力と役割を確認し、編成へ追加できます。手持ちが満員でも図鑑は閲覧できます。手持ちカードは四つの技・特性・装備をコンパクトに表示します。

## ウィンドウ

- 技・特性・装備：手持ちカードから個別編集。技は最大4つで、変更は即時に自動保存します。
- 編成の記録：3つの保存枠と保存結果を表示します。
- 音の設定：戦闘BGM・勝利音に共通のオン/オフと音量設定。再生の再試行が必要なときは画面上部に案内を表示します。
- 友だちと対戦：合言葉・部屋の作成・参加をまとめました。待機中に閉じると接続待機を中止します。
- 遊び方：相性表、能力の説明、状態異常の演出見本。閉じると演出見本のアニメーションも止めます。
- 幻獣：双方の一覧と交代をまとめました。長押しか「詳細」で、特性・持ち物・能力変化・設置を確認できます。

同じ設定要素をウィンドウへ移動し、閉じると元の待機領域へ戻すため、音量・保存ボタン・通信入力のイベントや値を失いません。背景を操作不可にし、Esc・背景クリック・閉じるボタンで閉じられます。Tabでフォーカスが外へ抜けず、閉じたときは起点の操作へ戻します。編集タブは左右矢印・Home・Endにも対応します。動きを減らす設定では画面とウィンドウの登場演出を止めます。

## 戦闘画面

PCでは戦場とコマンドを並べます。スマホではタイトルを省き、最上部に戦場を配置します。バトルログは戦場の下部へ重ね、HP・気力は小さくしました。四つの技の下に「気を溜める」「幻獣」を並べ、双方の一覧と交代はウィンドウへまとめています。詳しくは [スマホの戦闘画面](compact-battle.md) を参照してください。退出には確認ウィンドウを設け、決着後は三体を並べた結果画面へ進みます。

演出途中で退出して再出撃した場合、古い技・交代・ターン処理・結果画面のタイマーが新しい戦闘を変更しないよう、非同期処理の境界で戦闘の参照を確認します。バトルの能力値・技の効果・乱数の使い方は変えていません。

## 検証

`node tests/ui-overhaul.mjs` は実際のUIハンドラをDOM代替実装で実行し、図鑑・編成の追加/削除/並べ替え・四技制限・特性/装備・保存・ウィンドウ・フォーカス・キー操作・退出後の再出撃を検証します。従来のゲーム・保存・音・ドット描画を含む全12種類のNodeテストも実行します。

別途、実Chromiumで1360pxのPC幅と390pxのスマホ幅を確認しました。図鑑・編集・保存・音設定要素・友だち対戦ウィンドウ・AI戦のターン進行・戦況詳細・結果・編成への復帰を操作し、JavaScript例外と横方向のはみ出しがないことを確認しています。スクリーンショットで画面を確認して文字サイズ・カードの明度・出撃ボタンを調整しました。実際の2端末PeerJS通信と音の聴感は未検証です。
