# 身代わりの人形と技演出

身代わりの耐久がある間は、戦場の幻獣を32pxの布人形に置き換えます。味方は縫い目のある背面、相手はボタンの目のある正面を表示し、名前の横にも「身代わり」を表示します。人形は呼吸アニメーションで上書きされず、破壊・交代・解除後は通常の幻獣に戻ります。図鑑と編成の姿は変わりません。

命中しなかった技、属性無効の攻撃、条件不成立の技では技演出を表示しません。変化技は効果の適用前後を比較し、効果がなければ演出を抑えます。身代わりの重複・HP不足、能力上限、状態異常の防止、反響や封技の条件不成立などが対象です。守る・静養・アベコベルームの有効な再使用は演出を維持します。HP満タンでの回復では回復演出・回復量の表示を出しません。

ダメージ計算・命中・追加効果の乱数順序と身代わりの保護範囲は維持。成功した攻撃は各ヒットの演出を維持します。

全16種類のNodeテストが通過。新しいsubstitute-visual.mjsでは失敗・外れ・無効と成功の演出、前後の人形、元の姿への復帰、両視点、描画の非破壊性を検証します。Chromiumの360×640・390×844・1360×1000で実際の身代わり使用、待機中の表示維持、連続技による破壊後の復帰、横はみ出しなしを確認。実機Safariと2端末通信は未検証です。
