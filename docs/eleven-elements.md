# 11属性とシンボル

火炎・流水・草木・雷電・岩石・暗闇・大地・天空・幽玄・野生・無属性を採用。内部の既存属性キーは維持し、表示名だけ変更しています。既存18体の主属性と適性、保存済みの技・特性・装備は引き継げます。

相性は相談で合意した11×11表を実装。手引きに○＝2倍、△＝半減、✕＝無効、―＝等倍で表示します。ダメージ・AI・交代評価・編成の攻撃範囲も同じ表を参照します。アベコベルームでは無効も従来通り4倍になります。状態異常や設置の耐性は変更しません。

灯火の火・水・草・無SVGを引き継ぎ、承認された7属性のデザイン案を小さい表示に適したインラインSVGで実装。色だけでなく名前と形でも判別できます。技、図鑑、編成、戦場、詳細、相性表の共通チップに表示します。

野生は既存幻獣の主属性を変えず、技から導入します。かみつく：物理・威力60・命中100・気力20（焔犬、熔猪、蒼鮫、砂狼）。ひっかく：物理・威力40・命中100・気力10（雷鼬、蔦猿、砂狼、朧狐）。どちらも追加効果なしで、専用モーションを持ちます。

通信ルールはelements-eleven-v6へ更新し、旧版との対戦を開始しません。両者とも再読み込みが必要です。

`tests/elements.mjs` が合意表全121組、反転、名前・SVG、主属性維持、野生技の習得・ダメージ、表記を検証します。

全15種類のNodeテストが通過。実Chromiumの360×640・390×844・1360×1000で、シンボルと新属性名、相性表121セル、野生技によるターン進行、横はみ出しなしを確認しました。実機Safariと2端末通信は未検証です。
