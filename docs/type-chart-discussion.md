# 属性相性の議論メモ（未実装・継続検討）

## このメモの扱い

ユーザーの指示：議論は継続し、あとでまとめて変更する。現時点では相性表・新属性・特性を実装しない。この文書の候補を確定仕様として扱わない。次回の議論では、このメモとその後のユーザー発言を参照する。

## 基本方針と認識

- 相性の根拠で、同じ属性を「物質」「生物分類」「生態」「力」と都合よく読み替えない。
- 草木を草食動物と解釈することはやめる。植物の身体・成長・植物由来の力として考える。
- 野生は肉食動物限定ではなく、広く動物全般を想定する。「捕食者が草食動物を襲う」を野生→草木の抜群の理由にしない。
- 鳥＝天空という直感は残したい。整理案は、翼・風・飛行・空中活動と天空を結び付け、生物分類そのものと属性を同一視しないこと。草を食べるだけで草木とはならない一方、飛行は天空に直接つながる。
- 動物由来でも必ず野生を自動付与する、という結論にはしていない。火炎のライオン、天空の鯨など、主役となる力から属性を決める整理案を提示した。
- 属性全体に広く成立する関係は相性表、特定の生物だけの性質は特性、特定の攻撃方法は技や分類で表現する案。

## 野生・暗闇・草木の見直し候補

現在のゲームの値と、議論中の値を区別する。

|方向|現在|見直し候補|根拠と保留点|
|---|---:|---:|---|
|野生→草木|2倍|等倍|動物全般が植物全般に一律に強いとはしない。草木＝草食動物という説明を撤回。|
|野生→暗闇|2倍|半減|暗闇で相手の姿・位置を捉えにくくなり、身体と感覚を使う攻撃が阻まれるという解釈。候補段階。|
|暗闇→野生|半減|等倍|夜目が利くことを野生全体の耐性の根拠にしない案。野生→暗闇の半減から、逆方向の抜群が自動的に導かれるわけではない。|

これらを一度に適用すると野生の攻撃先と耐性を失うため、相性全体を再配分する必要がある。まだ反映しない。

### 夜目などの生態特性（未実装）

- 特性「夜目」で、暗闇との関係だけ有利にする案。ユーザーの表現は「1属性にだけピンポイントで追加の複合タイプのような状態」。
- 例として、暗闇属性の相手へのダメージ2倍／暗闇技からのダメージ半分を提示した。具体的な倍率・対象・攻守両方かは未確定。
- 現在の野生の相性へそのまま掛けると、暗闇へ4倍・暗闇から1/4になる。基本相性と特性を一緒に見直して重複強化を避けたい。
- 同様に草食・耐寒・鋭い嗅覚・反響定位などを、個々の幻獣の特性で表現する案。
- 夜行性と暗所視能力は同じではない。哺乳類には夜間に適応した種も多いが、野生動物全体が夜目に優れるとは断定しない。「生き物は必ず夜に不利」とも断定しない。

## 寒冷属性の追加検討（属性自体が未確定）

氷と水は同じ物質でも、流水＝流れ・浸透・侵食、寒冷＝冷却・凍結・活動低下として力や現象を分けられる。氷だけに限定せず、冷気や冬を含められる名称として寒冷を提案した。追加せず、流水技の内部分類に冷気を設ける代替案もある。

### 攻撃側の仮案

|寒冷技の相手|倍率案|
|---|---:|
|流水・草木・天空・野生|2倍|
|火炎・岩石・寒冷|半減|
|雷電・暗闇・大地・幽玄・無属性|等倍（未精査）|

- 初期案で草木・野生を等倍にしたが、ユーザーから「動植物の活動は寒さで低下・停止するので無理筋」と指摘された。その等倍案を採用案として復活させない。
- 自然な意味を先に立て、苦しくなる既存属性の相性も含めて再検討する。寒冷追加だけで全体のバランスが改善するとは決めていない。
- 岩石半減は、水を伴わない冷気だけでは岩を傷つけにくい、という仮の理由。霜による破砕など、再検討の余地はある。

### 寒冷→天空についての直近の議論

- 航空機の着氷は、重さだけでなく翼の形・表面を変え、揚力低下や抵抗増加を招く。ひこうへのこおり抜群の説明としてよく挙がるが、公式の採用理由だとは断定していない。
- ユーザーは、霜や空中の水分が凍るほどの冷却が飛行・空中活動に悪影響を及ぼす、という考えを提示した。
- 整理した理由：「寒冷は着氷や凍結によって、天空が得意とする飛行・空中での動きを妨げる」。この理由で寒冷→天空2倍を採るのはあり、とユーザーが納得した。実装の承認ではなく、採用寄りの候補として記録する。
- 風そのものが凍って止まる、寒いほどすべての風が弱くなる、とはしない。吹雪のように風と寒冷が強め合う場合もある。
- 属性内の全存在に例外なく当てはまる必要まではなく、特殊な浮遊や耐寒性は特性で例外を表現する案。

### 防御側の仮案

寒冷が受ける相性は火炎2倍・寒冷半減・それ以外等倍という初期案。これも未確定。

流水→寒冷を半減にすると、寒冷＋大地で流水弱点が打ち消され、草木だけ弱点・雷電無効・攻撃範囲も広い複合になりやすい。そのため流水→寒冷は等倍を提案した。

「岩で氷を砕く」を寒冷全体の弱点の理由にしてよいかは疑問があり、岩石→寒冷は等倍で仮置きした。

## バランス面で次に確認すること

- 寒冷→草木・野生を2倍とした場合、草木＋野生は寒冷も4倍弱点になり、火炎・天空・野生・寒冷の4種類が4倍になる。
- 暗闇＋野生は寒冷も2倍弱点になり、現在の表へ追加するだけなら弱点が計5属性になる。
- 野生→暗闇、暗闇→野生、野生→草木の見直し案を適用した場合は、上記の弱点数を再計算する。異なる案を混ぜた数字を確定値にしない。
- 寒冷が火炎だけ弱点のままだと、雨の火炎半減によってその弱点が等倍になる。等倍攻撃は普通に通るので無敵ではないが、耐久・習得技・天候との組み合わせを確認する。
- サランディ（大地＋天空）は寒冷が2倍弱点になる。ケファロック（岩石＋野生）は、最新攻撃仮案なら寒冷半減×野生2倍で等倍。初期の野生等倍案では半減だったので混同しない。
- ユダチョウ（火炎＋流水）は寒冷半減×2倍で等倍。火炎が寒冷への抜群相手を得る分、相対的な強化も検討する。
- 幽玄の抜群相手の少なさ、無属性の攻撃先などは寒冷を足すだけでは解決しない。
- 各属性の中心的な意味、攻撃側と防御側の理由、弱点・耐性・攻撃先、複合・天候・特性をセットで点検してから一括変更する。

## 今後の数値提案についてのユーザー方針

技などの気力が未指定なら既存基準から適切な値を設定する。指定された気力・威力などはそのまま実装する。その際、基準に比べ強すぎる／弱すぎるか、その理由と必要なら調整案も伝える。指定値は勝手に変更しない。
