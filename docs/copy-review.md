# 画面内の文言整理

編成・図鑑・設定・保存・通信・手引き・対戦結果を見直し、短い命令形や宣伝文句を機能名と案内に置き換えました。「選べ。組め。読み勝て。」「出会いが、戦略になる。」「幻獣を仕立てる」「契約中」などを整理し、敗北時の助言を結果表示に変更。保存の注意や技の効果など、操作に必要な説明は残しています。通信欄のシード交換など内部処理の説明は削除しました。

見直し中に、モチーフ別に追加した野生技が技選択のグループに含まれない不具合を修正しました。実際の習得リストから表示グループを生成し、既存属性・適性・共通技に加えてその他の習得技を選べます。属性・能力・技の効果・保存形式・通信ルールは変更していません。

既存15種類のNodeテストを実行し、野生技が実際の設定画面に並ぶ検証を追加。Chromiumで編成・技と特性の設定・相性表・野生技のターン進行を確認しています。
