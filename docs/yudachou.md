# ユダチョウと夕立

チャレンジの第2ボス。通常編成・通信チームには追加しない。火炎・流水、HP210／物攻45／物防80／特攻145／特防145／速度65（合計690）。ドット絵は湯釜の胴体、湯気の羽毛、長い首と脚を表現した32px前後像。

## 専用技と特性

- スチームチョイス：流水、特殊非接触、威力100、命中85、気力45、やけど50%。使用時に流水と火炎の相性を比較し、火炎の倍率が大きい場合のみ火炎にする。同率は流水。複合属性、野生回帰、アベコベルームも比較に反映。相手の特性は属性選択に影響しない。変化後の属性で一致補正・特性・演出色を判定。共有技定義は変更しない。
- 望まぬ夕立：流水の変化技、気力35。使用ターン終了から5回のターン終了に発動し、再使用で5回に更新。両陣営の場にいる生存個体だけが対象。交代・使用者の退場後も天気は残る。通常の雨のような技威力補正は追加しない。
- スチームタンク：流水攻撃を受ける代わりに、その計算ダメージ分を回復。守る・外れでは発動しない。流水吸収時は追加効果や被ダメ記録を発生させず、身代わりも削らない。火炎攻撃が本体に当たり生存すると特攻+1、上限+6。炎に対するダメージ軽減はない。無垢の仮面で両効果が無効。型破りは直接攻撃でのみ無視し、天気への影響はない。

## 夕立の計算

属性ごとに最大HPに対する割合を求めて合算し、最後に一度だけHPを変更する。
流水成分は-1/8（回復）。その他は「流水→その属性」の相性×1/8（ダメージ）。スチームタンク有効時は正の成分を回復へ変換する。

|属性・特性|合計|
|---|---|
|流水|-1/8|
|火炎・流水、特性なし|+1/8|
|草木・流水、特性なし|-1/16|
|火炎・流水、スチームタンク|-3/8|

割合を合算後、最大HPを掛けて絶対値を切り捨て（非ゼロは最低1）。回復は最大HPまで。倒れた個体は復活しない。霊体は正の間接ダメージを防ぐ。身代わり・守るでは天気を防げない。アベコベルームは技相性の効果なので天気の倍率は反転しない。野生回帰中の防御側野生成分は激化する。

特性を仮面で封じるとユダチョウも夕立で1/8ダメージを受ける。奇術・挑発・反響・封技・滅びの唄などの既存の攻略手段を維持。

検証はtests/yudachou.mjsと既存全テスト。実ブラウザ確認はChromium起動時のsetsockopt制限（Operation not permitted）で未完了。

## 夕立の連続阻止への対応

AIは夕立を実際におどかすで阻止した相手を記録する。同じ個体と対面し、使用可能な攻撃技がある場合は夕立を候補から外して攻撃へ切り替える。初回の阻止は有効で、相手の入力や未使用技を先読みしない。相手が変われば再挑戦でき、自分の交代・新しい対戦では記録を消す。反響の強制行動はこの判断より優先し、技制限や気力不足も維持する。
