# 技の属性の見直し

全62技を確認し、力の由来に合わせて11技を変更しました。技ID・威力・命中・気力・優先度・効果は維持しています。攻撃技には変更後の一致補正と相性が適用されます。

| 技 | 以前 | 現在 | 理由 |
|---|---|---|---|
| 結界 | 無属性 | 幽玄 | 霊的な障壁 |
| 砂かけ | 無属性 | 大地 | 土砂で視界を遮る |
| 不意打ち | 無属性 | 暗闇 | 身を隠し、隙を突く |
| おどかす | 無属性 | 野生 | 威嚇による行動妨害 |
| 砂礫 | 大地 | 岩石 | 岩や小石をぶつける |
| 根を張る | 大地 | 草木 | 植物の根で身体を支える |
| 翻し | 天空 | 野生 | 身体を翻して退く |
| 奇術 | 幽玄 | 無属性 | 手品による持ち物の交換 |
| 挑発 | 暗闇 | 無属性 | 言動で相手をあおる |
| 道連れ | 暗闇 | 幽玄 | 魂を結び付ける |
| 悪夢 | 暗闇 | 幽玄 | 夢と意識への干渉 |

精神統一・気合い・守る・身代わり・静養・体当たり・仕返しは特別な属性の力に限定しないため無属性を維持。幻痛・虚像斬・幻月・反響・封技・アベコベルーム・滅びの唄は霊的な作用として幽玄に残しました。痺れ砂は帯電した砂として雷電、白霧は霧として流水を維持しています。

技の属性と習得範囲を分けて管理します。従来の共通11技は属性が変わっても全員が習得可能。元の自属性・適性で習得できた技も保持し、新属性で習得する技と重複しないよう統合します。奇術・挑発が無属性になっても自動的に全員へ配りません。新しい自属性・適性の技として、野生の牙虎・荒熊は翻し、草木系は根を張るなどを習得できます。

全19種類のNodeテストが通過。新規テストで11技の変更、全20体の旧習得技と編成の保持、重複防止、奇術・挑発の配布制限、一致補正と無効を確認。実Chromiumのスマホ・PC幅で新しい属性表示、保存と再読み込み、実戦・交代を確認しました。通信ルールはmove-origins-v8へ更新。実機Safariと実通信は未検証です。
