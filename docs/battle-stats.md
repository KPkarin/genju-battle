# 物理・特殊と幻獣の役割

能力はHP・物攻・物防・特攻・特防・素早さの6つです。各技の分類は属性とは独立しており、同じ炎属性でも炎牙は物理、火炎放射は特殊です。

- 物理技：自分の物攻 ÷ 相手の物防を参照。
- 特殊技：自分の特攻 ÷ 相手の特防を参照。
- 変化技：ダメージを計算せず、能力上昇・回復・妨害などを行う。
- 仕返し：物理分類の固定ダメージ。物理・特殊の両方から受けた直接ダメージの1.5倍を返し、攻防値を参照しない。

## 使い方の目安

- **焔犬**：炎牙と岩技で攻める。不屈と気合いで物理火力を伸ばす。
- **潮亀**：高いHPと物理防御で受け、白霧や渦潮で相手の攻めを抑える。
- **苔獣**：両防御と光合成・寄生種で粘る。再生で交代を支える。
- **雷鼬**：最速級の素早さから物理の雷爪と特殊の雷撃を使い分ける。
- **岩牛**：最も高い物理防御で攻撃を受け、岩棘を置く。特殊技には注意。
- **影梟**：悪夢と雷撃の高い特殊火力で攻め、貪食で回復する。
- **土竜**：物理防御で受けつつ地響き・大地割で押し返す。
- **風燕**：翔撃で攻め、翻しと再生で味方へつなぐ。雷の特殊技も補助に使える。
- **熔猪**：物理耐久を活かし、地技と火炎放射を相手の守りに合わせる。
- **蒼鮫**：潮噛みと闇喰らいで一気に攻める。貪食で攻撃を回復につなげる。
- **蔦猿**：蔦打ち・闇喰らいと貪食で削りながら回復する。
- **雷鯰**：特殊技を受け、雷撃や濁流で反撃する。痺れ砂でも支援できる。
- **砕角**：最高の物理攻撃で岩・地技を通す。不屈や反骨でさらに強化。
- **宵蜘蛛**：耐久を活かして挑発・道連れで妨害する。草技で攻撃範囲を補い、霊体で間接ダメージにも強い。
- **砂狼**：大地割と炎牙で攻め、型破りで相手の防御特性を無視する。
- **雲鯨**：特殊技を受け、突風・水技で反撃する。威圧で物理側も補える。
- **夢貘**：特殊耐久と封技・反響で相手を止め、幻痛で気力を削る。
- **朧狐**：幻月・迅雷で攻め、見切りや好機を活かして先手を取る。

## 技・特性・装備

物理技が不足していた炎・水・雷に、炎牙・潮噛み・雷爪（威力75／命中100／気力30）を追加。精神統一は特攻+1、結界は特防+1で、どちらも無属性の汎用変化技です。既存53技と追加5技の全58技に分類を持たせています。

気合い・威圧・不屈・反骨は物攻、根を張る・影撫では物防に作用します。やけどによる攻撃低下は物理だけが25%減り、特殊攻撃は下がりません。毎ターンのやけどダメージは両方の型に発生します。守るは物理・特殊の両方を軽減します。白霧と交代では特攻・特防を含む能力変化をリセットします。

| 装備 | 効果 | 制約 |
| --- | --- | --- |
| 猛火の牙 | 物攻×1.2 | 同じ技を連続使用できない |
| 鋼の甲 | 物防×1.2 | 同じ技を連続使用できない |
| 霊力の珠 | 特攻×1.2 | 同じ技を連続使用できない |
| 霊紗の幕 | 特防×1.2 | 同じ技を連続使用できない |
| 戦装束 | 物防×1.35 | 変化技を使えない |
| 結界衣 | 特防×1.35 | 変化技を使えない |

AIは技の威力だけでなく、自分の物攻／特攻と相手の物防／特防を参照して技を評価します。保存済み編成は元の形式のまま読み込み、能力値は現在の種族データを使用します。古い編成では、物理型に特殊技だけが設定されている場合があります。分類表示と役割を確認して必要に応じて技を選び直してください。

通信対戦の開始時には `physical-special-motion-v2` のルール識別子を照合し、旧ルールのページとの対戦開始を防ぎます。バージョンが違う場合は双方でページを再読み込みしてください。
