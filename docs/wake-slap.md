# 目覚ましビンタ

暗闇・物理・接触、威力70、命中100、気力35。眠っている相手にはダメージ計算に使う威力を140にする。元の技データは変更しない。相手本体にダメージを与え、生存している場合に眠りを解除する。守る・外れ・無効・身代わりに当たった場合は起こさない。眠気や他の状態異常を解除しない。

先手で起こした場合、相手のそのターンの未実行の行動が可能になる。眠りを維持する利点を手放す技として扱う。

習得：カプケード、ワカクサル、ダマスデビル。演出、AIの条件付き火力評価、保存・通信に対応。

基準評価：威力80・気力35に比べ通常時は威力12.5%低い。眠り時の威力140は基準の1.75倍だが、睡眠解除で反撃を許すため、条件付きの高火力技。指定値を維持する。
