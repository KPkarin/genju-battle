# 接触技と護りの札

全62技に接触フラグを追加。特殊技と変化技はすべて非接触です。攻撃技は技選択・戦闘コマンドに接触／非接触を表示します。

接触する物理技：かみつく、ひっかく、炎牙、潮噛み、雷爪、体当たり、不意打ち、仕返し、蔦打ち、翻し、翔撃、闇喰らい。身体・牙・爪・自分の蔦などが相手に触れる攻撃として扱います。仕返しは受けた力を打撃で返す固定ダメージ技です。

非接触の物理技：種爆弾、葉の刃、粉砕岩、岩投げ、岩雪崩、岩の刃、砂礫、地響き、大地割、虚像斬、影撫で。葉の刃は葉を飛ばし、虚像斬は虚像に攻撃させ、影撫では伸ばした影で攻撃する技として説明を補いました。

毒棘は接触技が本体に命中した場合だけ発動し、従来どおり持ち主の最大HPの5%を攻撃者に与えます。非接触・外れ・無効・守る・身代わりへの攻撃では発動しません。持ち主が倒れた場合は従来どおり発動しません。毒棘は間接ダメージなので霊体で防げます。固定反撃も同じ判定処理へ統一しました。

護りの札は攻撃直前のHPが最大HPと等しい場合のみ、1回だけHP1で耐えます。少しでも減っていれば発動せず、使用済みにもなりません。未使用なら満タンまで回復した後に発動できます。連続技の後続ヒットはそのまま当たり、滅びの唄・道連れは従来どおり耐えられません。

通信ルールはcontact-charm-v10。双方とも再読み込みが必要です。全22種類のNodeテストが通過。新規テストで全技の区分、毒棘の接触判定と防御、満タンと1減少・半分の境界、1回限りの発動、連続技の継続を検証。Chromiumの360・390・1360px幅で表示、接触と非接触での実戦比較、満タン時だけの護りの札の発動を確認しました。実機Safariと実通信は未検証です。
