# 気力・守る・行動制限の調整（2026-11-13）

- 自然回復：ターン終了時12。気力帯は追加8（合計20）。控えには自然回復しない。
- 守る以外の技：同じ技の連続使用は基本消費、+5、+10…と増加。別の技、気力溜め、交代、やけくそでリセットする。命中しなくても消費・加算される。麻痺・ひるみ・反動などで実行できなかった場合は加算しない。
- 守る：専用の30→60→120…を維持。一般の+5加算とは重複しない。
- 集中：気力上限・開始時気力150、気力溜めの回復量50、溜める際の被ダメ増加なし。自然回復込みでは62。通常の気力溜めは25+12=37、被ダメ1.2倍。
- 無垢の仮面で集中が無効になった場合、上限100になり、超過分を切り捨てる。仮面を外しても気力は補充されない。
- 好機：先手なら追加効果確率1.5倍。見切りの半減も適用。はにうんどうの砂嵐中2倍は維持。

## 守るの範囲

攻撃ダメージ・追加効果に加え、直接対象に作用する砂かけ・熾火・寄生種・渦潮・奇術・反響・封技・挑発を防ぐ。防がれた側は気力を消費し、連続使用にも数える。技の命中演出は出ない。

自分への強化・回復、天気、アベコベルーム、白霧、滅びの唄、設置は防がない。既にかかっている状態異常・寄生・滅びなども解除しない。サンドブレイクの攻撃・ひるみは防ぐが、使用時の砂嵐は発生する。

## 反響・封技・挑発の持続

いずれも相手の行動機会3回分。行動前にかけると使用ターンから、行動後なら次ターンから数える。麻痺・ひるみ・反動で動けないターンも行動機会として数える。交代すると解除する。

相手の前ターンの守るを先手で反響・封技の対象にできる。ただし守る自体は優先度+4なので、相手が今ターンも守るを選んでいる場合は通常の反響・封技より先に発動する。
