# おまかせ編成のルール

プレイヤーのおまかせボタン、初回の自動編成、コンピューター側の編成に共通の生成処理を適用します。3体は重複なしで抽選し、各個体は持ち物→攻撃技→変化技→特性の順に決めます。手動の編集や保存済み編成には制限を追加しません。

- 属性一致の攻撃技を必ず1つ選択。威力0の固定反撃では一致技の条件を満たしません。
- 技制限のない持ち物は攻撃2・変化2。変化技禁止、同じ技の連続使用禁止の持ち物は攻撃4。
- 猛火の牙は物理攻撃、霊力の珠は特殊攻撃に統一。対応する一致技や4技が確保できない持ち物は候補から除外。攻防値を使わない仕返しは、これら攻撃強化アイテムでは選びません。
- 攻撃2技を決めた後、通常の物理攻撃がない場合は気合い、特殊攻撃がない場合は精神統一を変化技の候補から外します。防御・特殊防御の上昇は攻撃分類に依存しないため対象外です。
- 不屈・反骨は物攻を使う攻撃がある場合のみ。好機は実際に確率抽選される追加効果を持つ攻撃がある場合のみ。発動率0%や100%の効果は対象外。
- 無垢の仮面は奇術を覚える場合のみ抽選し、必ず奇術を選択。相手へ渡した後に選んだ特性を使える構成にします。
- 技は重複なし、習得可能なものだけを選択。種族と候補の抽選はシード付きのFisher–Yates方式です。

全21種類のNodeテストが通過。smart-builds.mjsでは16,080件を生成し、全種族と利用可能な各持ち物、通常抽選、属性一致・技数配分・強化先・特性・仮面・保存/通信の形式・乱数再現性・元データ非破壊を確認しています。Chromiumの360・390・1360px幅で実ボタンを各12回操作し、編成が有効なこと、再読み込み後の保存、対戦の開始とターン進行を確認しました。実機Safariと2端末通信は未検証です。戦闘ルール自体は変わらないため通信ルール番号は維持しています。
