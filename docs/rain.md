# 天候「雨」

- 雨乞い：流水の変化技、気力35。使用ターンを含む5回のターン終了まで雨。
- 雨獣：生存して場に登場したとき、天候を5ターンの雨にする。無垢の仮面で無効。特性が無効になったり退場した後も、既に発生した雨は継続する。再登場で残り5ターンに更新する。
- 流麗：雨の間、属性に関係なく素早さ2倍。他の素早さ補正や麻痺と重複し、無垢の仮面で無効。
- 雨の間は流水の攻撃ダメージ1.5倍、火炎の攻撃ダメージ半分。物理・特殊、敵味方の双方に適用。
- 雷撃・迅雷は必中。命中・回避ランク、風纏による命中低下を受けないが、守る・属性無効などは通常どおり。元の技データは変更しない。
- 雨、夕立、砂嵐は1つの天候枠を共有する。望まぬ夕立は実行時に雨なら失敗し、雨を上書き・延長しない（気力と使用記録は消費する）。それ以外の天候変更は上書きする。通常の雨は割合ダメージや回復を発生させず、夕立は今回の雨補正を受けない。

## 既存幻獣への追加

ミズカガメ・イナマヅ・ホゲールに雨乞い。ホゲールに3つ目の特性として雨獣、イナマヅに3つ目の特性として流麗を追加。既存特性と保存済み編成は保持。カバの新種は未追加。

おまかせ編成の流麗は、自身の技に雨乞いがある場合に選ぶ。AIは雨の技威力・必中補正と雨乞いの価値を判断する。通信ルール識別子はrain-v22。
