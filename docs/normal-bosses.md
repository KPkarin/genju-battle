# 元ボス3体の通常実装

|通常幻獣|HP|物攻|物防|特攻|特防|素早さ|合計|
|---|---:|---:|---:|---:|---:|---:|---:|
|ケファロック|140|120|115|40|85|50|550|
|ユダチョウ|130|40|65|125|125|65|550|
|サランディ|120|45|85|110|85|105|550|

専用技・特性は共用する。通常版にはいしあたま／不屈、スチームタンク／早熟、はにうんどう／見切りをそれぞれ設定。モチーフと役割に沿った個別習得技を追加する。通常図鑑は25体。

チャレンジでは「ボスケファロック」「ボスユダチョウ」「ボスサランディ」と表示し、従来のHP500／450／480を含むボス能力値と専用構成を維持する。通常の種族検索は通常版の値を返し、チャレンジ構築のbossフラグがあるときだけチャレンジ用の能力値と道連れ・滅びの唄への耐性を使う。

保存・おまかせ・通信対戦では通常版として扱い、通信チームのbossフラグは検証時に落とす。既存種族ID、画像、過去の編成保存キーは維持。既存22体の並び順を保ち、新たな3体を末尾に追加する。

tests/normal-bosses.mjs：通常版とチャレンジ版の名前・能力・即死技処理の分離、専用技、通常おまかせ構成、保存、通信検証を確認する。
