# 騙し合い・殺息・お隣いかが

## 騙し合い

暗闇の変化技。気力30、命中100、通常優先度。先手ならそのターン、後手なら次のターンの行動を変化技に制限する。攻撃技を選んでいた場合は実行前に失敗し、気力は消費しない。交代で解除できる。守るで防ぐ。身代わりは他の行動制限技と同様に防がない。

前ターンから制限が続いており、気力・挑発・封技・反響・持ち物・全力シリーズの固定などによって使用可能な変化技が1つもない場合、居座るとやけくそ（攻撃扱い・最大HP20%の自傷）になる。選択時の強制行動にも反映し、不意打ちが成功する。気力溜めで制限を回避することはできない。反動や眠りなどで行動自体ができない場合はそちらを先に処理する。

習得：メイホー、フォクシャドウ、コモリクモ。

## 殺息

野生の変化技。気力35。自分の物理防御を1段階下げ、回避を2段階上げる。ランク範囲は-6〜+6。回避が上限でも防御低下は発生する。

習得：ダマスデビル、ワイルドラ、ジョウルフ。

## お隣いかが

幽玄の変化技。気力35。自分の物理防御+1。「眠気を誘おうとしている」と表示し、次の自身の行動機会まで、本体に接触してきた相手を眠気にする。使用者が後手なら、次ターンの自身より速い接触攻撃にも反応する。次の行動機会が来た時点で解除し、ひるみ・眠り・反動で動けない場合も終了する。交代・戦闘不能でも解除する。

守る・身代わりで受けた攻撃、非接触攻撃、外れ、無効では眠気を付けない。接触した側が身代わり・通常状態異常・発症予約・既存の眠気を持つ場合も付与しない。

習得：バクネス、フォクシャドウ、コモリクモ。

## 眠気と眠り

眠気を受けたターンをTとすると、T+1のターン終了時に眠りへ変化する。眠気は交代で解除される。付与後に身代わりを作っても発症は防がない。途中で別の通常状態異常が付いた場合は眠りに上書きしない。

眠りは通常状態異常の枠を使い、発症時に1〜3回の休みを均等に抽選する。抽選に戦闘用乱数を使用し、通信双方で同期する。その回数の行動を休んだ後に目覚め、次の行動から動ける。交代しても眠りと残り回数は維持する。早熟・癒しの鈴など通常状態異常の治療に対応する。やせ我慢は眠りの発症も次のターン終了まで遅らせる。
