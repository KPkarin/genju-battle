# 技ごとのモーション

全58技に `MOVE_MOTION_PROFILES` を割り当て、384×216の透過キャンバス上へ整数座標のドットで描画します。属性と技の分類は戦闘データ、形・大きさ・数・本体動作は演出データとして独立しています。

| 例 | 本体の動作 | エフェクト |
| --- | --- | --- |
| 炎牙・潮噛み・闇喰らい | 踏み込む | 大きさや歯数の異なる上下の牙 |
| 雷爪・影撫で・葉の刃 | 踏み込む | 爪の軌跡・舞う葉刃 |
| 火の粉・火炎放射・業火 | 構える／反動 | 数や広がりの異なる炎の流れ |
| 水鉄砲・濁流・大波 | 構える／浮き上がる | 水流・押し寄せる波 |
| 静電気・雷撃・迅雷 | 構える／浮き上がる | 放電・複数の落雷 |
| 岩投げ・岩雪崩・岩の刃 | 構える／踏み込む | 落石・岩の結晶 |
| 地響き・大地割 | 踏ん張る／反動 | 伸びる亀裂・飛び散る土 |
| 突風・翔撃・翻し | 構える／浮き上がる／踏み込む | 風の筋・斬撃 |
| 幻月・悪夢・滅びの唄 | 構える／浮き上がる | 三日月・悪夢の目・流れる音符 |
| 守る・結界・光合成 | 踏ん張る／浮き上がる | 盾・結界・回復の光 |

`drawMoveMotion(ctx,key,progress,from,to,kind)` は盤面や戦闘乱数を変更せず描画します。`MoveMotion.play()` が技に合わせた本体動作と約620msのエフェクトを開始し、新しい技・画面移動・終了・切断・非表示で確実に片付けます。ミス時は着弾点を外し、動きを減らす設定では本体を動かさず短い静止エフェクトだけを表示します。

自分の幻獣は後ろ姿のまま、手前から奥へ踏み込みます。通信対戦でも各端末の自分側を基準に向きを変えます。被弾点滅もこの視点に合わせています。

`node tests/move-motion.mjs` は全58技・両方向・フレーム差分・整数描画・盤面と乱数の非変更・終了処理を検証します。実ブラウザでの見え方やタイミングは、このテストとは別の確認が必要です。
