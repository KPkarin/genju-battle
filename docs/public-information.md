# 対戦中の公開情報（2026-11-23）

相手側は、登場・技の使用・効果の発動など、対戦中に確認できた情報だけを一覧と詳細に表示します。自分の編成と詳細は引き続きすべて確認できます。

- 未登場の相手は「？」。一覧の枠数は公開しますが、名前・属性・画像・状態・詳細操作を隠します。開始ログでも編成を公開しません。
- 登場後は名前・属性、HP割合、公開された状態と能力ランクを表示します。正確なHP・能力実数値・気力・身代わり耐久・持ち物による技固定の内部状態は表示しません。
- 技は使用が宣言された時点で記録。外れた技、防がれた技も記録します。眠りや凍結で使用前に止まった技は記録しません。
- 特性は天候・威圧・反骨など、名前が明示される発動で判明します。常時補正から自動で特性名を確定させることはありません。
- 持ち物は護りの札・癒しの鈴・毒棘・命の実・飲み物の発動、持ち物が原因と明示された使用失敗、成功した奇術による交換で判明します。消費後は現在の「持ち物なし」と確認履歴を表示します。未判明と持ち物なしは区別します。
- 控えは最後に確認した状態を表示。交代時に公開された回復や状態解除を記録した後、裏で状態が変わっても再登場まで更新しません。

`BattleIntel` は実際の戦闘状態 `B` と別に、陣営ごとの観測記録を保持します。視点を反転する通信対戦でも、相手側だけを隠します。新しい `B` へ切り替わると記録はリセットされ、保存済み編成は変更しません。表示や記録は対戦乱数を消費しません。

コンピューターは自分の編成を参照し、相手については観測記録から作った推定用の幻獣を使います。未判明の特性・持ち物の補正は適用せず、見せていない技、内部の能力値変更、現在の入力は評価に使いません。未判明の持ち物に対する奇術は成功の可能性を見込み、実行時に本来の成否を判定します。技ボタンの効果予告と詳細も公開情報に基づきます。

現在の通信方式は両端末で戦闘状態を再現する方式です。この変更は通常のゲーム画面とAIの参照範囲を制限します。通信相手の端末へ非公開データそのものを送らない構成には、将来サーバー側で戦闘を管理する方式が必要です。

## 検証

- `node tests/public-information.mjs`：発見イベント、未登場、控えの観測固定、対戦リセット、非公開情報だけを変えた場合のAI選択の一致。
- `node tests/compact-battle.mjs`：両視点での未知枠・自分の交代操作・詳細閲覧。
- `python tests/public-information-browser.py --url http://127.0.0.1:8771/`：実際のブラウザで両視点の非表示・発動後の開示・HP割合・控えの最終確認状態を検証。
