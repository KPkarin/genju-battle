# 新幻獣48体のドット絵候補

このフォルダは未採用の案を保管する素材庫です。ゲームの幻獣一覧には登録していません。

- 全48体、正面と背面の2方向。ネイティブサイズは128×128、透過PNG。
- `creatures-front.png` と `creatures-back.png` は8列×6行、1024×768のアトラスです。
- `manifest.json` の番号・名前・`atlasRect` が両アトラス共通の対応表です。番号は既存幻獣の番号とは別の、案001〜048です。
- `concepts.json` に名前の語源、属性、能力値、技・特性、評価を保管しています。これらは確定仕様ではありません。
- 正面と背面を組で同じ縮尺にし、最近傍処理でサイズを統一。各画像最大40色、外周に透明余白、基準の接地線はy=120付近です。
- 白・青の配色に暖色フィルターを加えていません。元案で指定した暖色部分のみ保持しています。
- 拡大表示は `image-rendering:pixelated` を使います。アトラス1枚を拡大縮小してから切り出すと輪郭が混ざるので、128×128の矩形を先に切り出してください。
- 静止画の素材です。呼吸アニメの部位別レイヤーやゲームへの登録は、採用した幻獣ごとに調整します。

`validation.json` には96枚のサイズ・透過・外周・色数と、アトラスへの往復一致の検証記録があります。
