# 幻獣闘記の高速自動対戦

Node.js 22以降、追加パッケージなしで実行できます。

```sh
node tools/selfplay/run.mjs --games 10000 --seed 20261123 --out selfplay-results
node tests/selfplay.mjs
```

`index.html` の実際の戦闘処理・技・編成生成・公開情報モデルをVMで実行します。描画、音、ログの待ち時間、コマンドUIを省きます。基準AIの評価関数は同じソースから陣営参照だけを変えて両側に適用します。相手の未判明の技・持ち物・特性や選択中のコマンドは評価しません。

- 同じシードの編成で2戦行い、左右を交換します。これは行動順や乱数まで完全に対称になる保証ではありません。
- 強制交代・翻しの交代先は、両側とも生存している最初の控えを選びます。プレイヤーの交代判断を再現するものではありません。
- 通常3対3が対象。ボス戦は含めません。
- 1戦150ターンを上限にし、勝者が決まらなければ `turnLimit` と記録します。擬似勝者を作りません。
- 試行中にエラーが出たら記録して停止します。タイムアウトも失敗として扱います。
- `games.jsonl` に1戦ずつ追記、50戦ごとと終了時に `summary.json` を保存します。同じ引数で再実行すると途中から再開します。中断時の最後の不完全行も修復します。
- 編成、乱数シード、左右交換、エンジンのSHA256、勝敗、ターン数、最後の40件のログを保存します。ソースや条件を変えた場合は別の出力フォルダを使います。
- `SIGINT` / `SIGTERM` を受けると進行中の1戦の後で保存して停止します。

GitHub Actions の **Battle self-play** は登録時と毎日日本時間04:23頃に1万戦を実行し、結果を90日間アーティファクトとして保存します。混雑で開始が遅れることがあります。手動実行も可能です。ジョブ上限は15分、リポジトリへの書き込み権限はありません。停止はActions画面からこのワークフローを無効にします。定期実行の計算はGitHub側で行われ、チャットのモデルを呼びません。

現段階は基準AIの経験データ収集です。ランダム編成のキャラ別勝率は、持ち物・仲間・対戦相手・技構成の影響を含むため、そのままキャラの強さとは判断できません。新しい判断候補の採用には、別シードと固定対戦条件での比較が必要です。公開ゲームのAIや能力値を自動変更する機能はありません。
